# הערות פרטיות למי שמפעיל את הבוט

אם אתם מארחים את Pika למשפחה או לחברים, אתם אחראי המידע על ההודעות, המיילים והיומן שלהם. זה מה
שהתוכנה באמת עושה, כדי שתוכלו לומר למשתמשים את האמת (התשובה של הבוט עצמו ל"האם המידע שלי פרטי?"
נוצרת מאותן עובדות). המקור האנגלי: [PRIVACY_FOR_OPERATORS.md](./PRIVACY_FOR_OPERATORS.md).

## מה יוצא מהמחשב שלכם

| מידע | נשלח אל | מתי |
| --- | --- | --- |
| הודעת המשתמש, עד 10 ההודעות האחרונות מ-24 השעות האחרונות, שמות אנשי קשר שמורים, עובדות שמורות | Google Gemini API (או **OpenAI**, למשתמשים שבחרו בו ורק אם הפעלתם אותו) | כל הודעה |
| תמונות, הודעות קוליות וקובצי PDF שהמשתמש שולח | מטא (הורדה) ← Gemini | בעת השליחה |
| טקסט ההודעות | Gemini embeddings API | נשמר לחיפוש סמנטי ("מה אמרנו על X") |
| נושאי מיילים/גופם, אירועי יומן | Gemini | רק כשהמשתמש שואל על מייל או יומן |
| **מצב יזום בלבד:** שולח + נושא + תקציר קצר של מייל חדש; אירועי יומן קרובים | Gemini | אופציונלי, לכל משתמש, נבדק ברקע; לזיהוי וניסוח בלבד |
| שאילתות חיפוש | Gemini עם Google Search | "מה קרה עם X" |
| מספרי מעקב | Ship24 | מעקב חבילות |
| שמות ערים | Open-Meteo | מזג אוויר |
| סימולי מניות | Yahoo Finance | שערים |
| טקסט תזכורות והתראות | טלגרם Telegram Bot API | כל הודעה יוצאת |

אם מפעילים את OpenAI (`OPENAI_API_KEY` + `OPENAI_MODEL`), התוכן של אותם משתמשים נשלח אליו במקום ל-Gemini, עם `store: false`
(בקשה, לא הבטחה); חיפוש בזיכרון ויצירת תמונות עדיין משתמשים ב-Gemini. דף `/privacy` והודעת ההיכרות מציינים את OpenAI אוטומטית.
בדקו את תנאי השימוש במידע של OpenAI עבור החשבון שהמפתח שלכם שייך לו.

Google מצהירה שמידע מה-API אינו משמש לאימון המודלים שלה בפרויקטים בתשלום, אבל זו מדיניות של Google,
לא משהו שהתוכנה אוכפת. קראו את תנאי התוכנית שהמפתח שלכם נמצא בה.
**בשכבה החינמית Google עשויה להשתמש בתוכן שנשלח לשיפור המוצרים שלה, ובני אדם עשויים לעבור עליו**,
וזה סותר את הצהרת ה-Limited Use בדף `/privacy`: השתמשו בפרויקט עם חיוב אם מישהו מחבר את Google.

## מה נשמר (קובץ SQLite אחד, `DB_PATH`)

הודעות והטמעות שלהן, אנשי קשר, עובדות שנזכרו, תזכורות, צילומי קישורים שמורים, טיוטות, מעקבים,
חבילות, לוחות זמנים של ילדים, הגדרות מצב יזום/רשימת VIP, ו**אסימוני Google OAuth (מוצפנים עם
`TOKEN_ENCRYPTION_KEY`, Fernet)**. הרישום של המצב היזום שומר *מזהי* הודעות, תקצירי אירועים ויומן קצר של מה נשלח.

- **לא מוצפן במנוחה** מלבד אסימוני Google: הגנו על הדיסק והגיבויים. הגיבויים מכילים את היסטוריית השיחות של כולם.
- **שמירה:** היסטוריית השיחות נשמרת עד שהמשתמש אומר "תמחק את ההיסטוריה שלי" (או שאתם מוחקים את
  בסיס הנתונים). טבלאות הרישום של המצב היזום מנוקות אוטומטית אחרי 60 יום.
- כל משתמש יכול לבקש "תראה לי מה יש לך עליי" (ספירות בלבד) ו"תמחק את ההיסטוריה שלי".

## מי יכול לראות מה

- משתמשים מבודדים זה מזה: הטבלאות מסוננות לפי משתמש, ופעולות שמקבלות מזהה מוודאות בעלות.
- לוח הניהול מציג ספירות, תזכורות פעילות ושימוש - **לא תוכן הודעות או מיילים** - וכל צפייה או פעולה
  של מנהל נרשמת ב-`admin_audit_log`.
- אתם, עם גישת shell למארח, *יכולים* לקרוא את בסיס הנתונים. אל תגידו למשתמשים אחרת.
- הלוח כבוי עד שמגדירים `ADMIN_ALLOWED_EMAIL`, מוגש רק על `ADMIN_HOST`, ומומלץ להציב אותו מאחורי
  Cloudflare Access עם `CF_ACCESS_TEAM_DOMAIN`/`CF_ACCESS_AUD` כדי שהבוט יאמת את האסימון החתום. אל תחשפו אותו בשם המארח הציבורי.

## הזרקת הנחיות ואישורים

תוכן של מיילים ושל רשת נחשב לבלתי מהימן. הבוט לעולם לא שולח מייל בלי אישור מפורש של המשתמש, והודעות
יזומות רק *מספרות* למשתמש - כל פעולה מוצעת עוברת את אותו שלב אישור.

## לפני שמצרפים אנשים נוספים

1. הסבירו להם בשפה פשוטה מה בטבלה שלמעלה.
2. פרסמו דף פרטיות ותנאי שימוש - הבוט מגיש `/privacy` ו-`/terms` (הגדירו `ADMIN_CONTACT_EMAIL`); מסך
   ההסכמה של Google דורש אחד. ראו [TERMS_TEMPLATE.he.md](./TERMS_TEMPLATE.he.md).
3. החליטו כמה זמן שומרים גיבויים, ומחקו את המידע של מי שעוזב (`delete_history` והסרת המשתמש).
4. אם אתם כפופים ל-GDPR או לדומה, זה כלי לשימוש אישי/משפחתי מעיצובו; הפעלה לציבור היא בעיית
   ציות אחרת שהפרויקט הזה לא פותר.
